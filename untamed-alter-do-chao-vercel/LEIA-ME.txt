ALTER DO CHÃO — PACOTE PARA GITHUB + VERCEL

Endereço planejado: https://untamed-amazon.com.br/alter-do-chao
A publicação e a associação do domínio devem ser feitas na sua conta Vercel.

CONTEÚDO
- alter-do-chao.html: página completa, com CSS, JavaScript e fotos embutidas.
- vercel.json: ativa endereços sem a extensão .html.
- LEIA-ME.txt: estas instruções.

USAR NO MESMO REPOSITÓRIO DO SITE ATUAL (HTML ESTÁTICO)
1. Descompacte o ZIP no computador. Não envie o ZIP fechado para o GitHub.
2. Abra no GitHub o repositório conectado ao projeto Vercel que atende ao domínio.
3. Clique em Add file > Upload files.
4. Envie alter-do-chao.html para a mesma pasta em que está o index.html atual.
   Preserve o index.html e os arquivos das outras páginas.
5. Se NÃO existir vercel.json, envie também o vercel.json deste pacote para
   a raiz do projeto. Se JÁ existir, preserve a configuração atual e acrescente
   apenas a propriedade "cleanUrls": true ao objeto JSON existente. Não
   substitua configurações ou regras de outras páginas.
6. Clique em Commit changes. Se a implantação automática do GitHub estiver
   ativa, a Vercel publicará a alteração. Caso contrário, execute Redeploy.
7. Com a publicação concluída e o domínio associado ao mesmo projeto, abra:
   https://untamed-amazon.com.br/alter-do-chao

DOMÍNIO
Se o domínio ainda não estiver associado ao projeto, acesse Vercel > projeto >
Settings > Domains, adicione untamed-amazon.com.br e siga os registros DNS
que a Vercel mostrar para configurar no provedor do domínio.
Comprar o domínio, por si só, não associa a hospedagem à Vercel.
O pacote usa o domínio .com.br solicitado nesta conversa.

SE FOR UM PROJETO NOVO, APENAS PARA ESTA PÁGINA
Envie alter-do-chao.html e vercel.json para a raiz de um novo repositório.
Na importação para a Vercel: Framework Preset = Other; Root Directory = raiz;
Build Command desativado/vazio; Output Directory = . (diretório atual).
A página será servida em /alter-do-chao. O pacote não cria uma página para /.
Para o endereço no domínio funcionar, o projeto precisa receber esse domínio.
Se o domínio já atende a um site existente, use o MESMO projeto/repositório
conforme a primeira opção, para manter as páginas no mesmo endereço.

SE O REPOSITÓRIO UTILIZAR NEXT.JS OU OUTRO FRAMEWORK
Coloque alter-do-chao.html na pasta public do projeto, preserve o build atual e
integre a configuração de URL à configuração já existente. Este pacote está
preparado principalmente para a publicação HTML estática utilizada antes.

FUNCIONAMENTO
- Design e conteúdo da última versão aprovada.
- Botões arredondados, sem setas e com maior destaque.
- Valores por saída disponíveis em “Ver investimento”.
- Fotos incorporadas ao HTML, inclusive no roteiro interativo.
- O formulário prepara uma mensagem para o WhatsApp comercial da Untamed.
  O visitante conclui o envio no WhatsApp. Não há integração com RD Station,
  banco de dados, autenticação ou confirmação automática de reserva.
- Não requer instalação de dependências ou variáveis de ambiente.
- É possível abrir o HTML diretamente no navegador para conferir o conteúdo.
